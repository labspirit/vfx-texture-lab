# Ember · Texture Studio

`Ember.html`을 더블클릭해 Chrome 또는 Edge로 열면 됩니다. 파일 하나만 다른 폴더로 옮겨도 작동합니다. 설치, 서버, 인터넷, 계정, API 키가 필요 없습니다.

선택한 **원본 밀착형**을 구현했습니다. TextureCreate의 레이어 목록 → 소재 속성 → 중앙 미리보기 → 전역 설정·애니메이션·후처리 배치를 참고한 독립적인 도구입니다. AI 모델이나 외부 서비스는 사용하지 않습니다.

## 편집

- 레퍼런스의 소재 이름·순서 117종을 모두 포함합니다. 분류는 방사형·링, 도형·버스트, 패턴, 그라데이션, 노이즈·텍스처, 자연, 디지털, 기타의 8개입니다. 기존 Stripe와 Slash를 포함하면 총 119종입니다. 소재 공식은 독립적으로 구현했으며 원본과 픽셀 단위로 동일한 결과·세부 파라미터를 보장하지는 않습니다.
- 타입 선택은 분류별로 묶었으며, 소재 라이브러리에서 검색·분류 필터·즐겨찾기·최근 사용을 지원합니다. 별 버튼으로 즐겨찾기를 바꾸며 목록은 브라우저에 보관합니다.
- 최대 8개 레이어. 표시/숨김, 복제, 삭제, 순서 변경, 이름, 불투명도, 일반/더하기/곱하기/스크린/마스크 합성.
- 레이어마다 시드, 노이즈, 왜곡, 크기, 회전, 오프셋, 스케일, 스크롤, 극좌표, 흑백 반전.
- 전역 효과: 블러, 디렉셔널 블러, Bloom, 샤프니스, 픽셀화, 색수차, 비네트, 스캔라인, 만화경, 미러 타일, 스월, 에지, Toon 계조, 비네트 마스크.
- 2~8개 색 정지점. 색·위치 편집, 램프 클릭으로 정지점 추가, 색 프리셋 8종.
- PNG 미리보기 채널: RGBA, 알파, RGB. 체커/검정 배경은 미리보기용이며 내보내기 투명도와 별개입니다.
- 실행 취소/다시 실행과 자동 임시 보관. 브라우저가 로컬 저장소를 허용하지 않는 경우에도 JSON 저장은 가능합니다.

## 애니메이션

재생 버튼, 시간 탐색, 속도, FPS, 길이, 루프를 지원합니다. 실제 한 번의 재생 길이는 **설정 길이 ÷ 속도**입니다. 예: 길이 2초, 속도 2이면 실제 재생은 1초입니다.

루프를 켜면 시간에 따른 노이즈 좌표를 주기적으로 계산합니다. 애니메이션 시트와 GIF는 첫 프레임을 마지막에 중복하지 않고 한 주기를 샘플링합니다. 공간 타일링은 별도의 **심리스 타일링 생성** 옵션으로 적용합니다.

## 작업 영역 · 줌 · 패닝

- 실제 이미지 영역만 체커 배경으로 표시하고 보라색 테두리를 그립니다. 바깥 작업 공간과 구분되며, 경계와 체커는 파일에 저장되지 않습니다.
- **경계 표시**를 끄면 원본·반복 타일의 테두리와 캔버스 크기 표기를 숨깁니다. 체커는 별도 옵션입니다. 이 설정은 브라우저에 보관되며 내보내기 이미지에 영향을 주지 않습니다.
- 마우스 휠: 커서 위치를 기준으로 확대·축소(2~1600%).
- 왼쪽 또는 가운데 버튼을 누르고 드래그: 패닝. 가운데 버튼 자동 스크롤은 작업 영역에서 차단합니다.
- **화면 맞춤** 또는 작업 영역 더블클릭: 중앙 정렬 및 크기 맞춤. **100%**: 프로젝트 픽셀 기준 배율.
- **타일 반복 보기**: 현재 줌과 이동 위치를 유지하면서 한 장을 3×3으로 반복합니다. 가운데가 원본 타일입니다. 반복 보기와 카메라 이동은 출력 파일에 반영되지 않습니다. 반복 전체를 보고 싶으면 화면 맞춤을 누릅니다.

## 극좌표 · UI 크기

**극좌표 변환**은 선택 레이어를 먼저 이미지로 렌더링한 다음, 가로축을 각도·세로축을 반지름으로 변환합니다. 노이즈뿐 아니라 소재·회전·오프셋·반전이 적용된 실제 그림 전체가 감깁니다. 원 바깥은 투명하게 처리하고 이후 다른 레이어와 합성합니다.

**디렉셔널 블러**는 포스트 이펙트에서 켜고 펼쳐 강도(0~64px)와 방향(-180~180°)을 조절합니다. 0°는 가로, 90°는 세로 방향입니다.

상단 **UI 크기**로 80~140% 배율을 조절합니다. 중앙 화면 양옆의 구분선을 드래그하면 소재·후처리 패널 폭을 각각 바꿀 수 있습니다. 구분선 더블클릭 또는 Home은 해당 폭을 초기화하며, 키보드 좌우 화살표도 지원합니다. **UI 초기화**는 화면 설정만 초기화합니다. UI 설정은 텍스처 프리셋과 별도로 브라우저에 보관합니다.

## 심리스 타일링 생성

오른쪽 **심리스 타일링 생성**을 켜면 후처리 결과의 좌우·상하 경계를 교차 블렌딩해 서로 맞춥니다. **타일 경계 블렌드**로 가장자리 보정 폭을 조절합니다. 경계의 모양은 보정 과정에서 달라질 수 있습니다. PNG·GIF·시트·알파·노멀·패킹에 같은 설정을 적용하고, JSON 프리셋과 시트 메타데이터에도 보관합니다. 노멀맵의 경계 미분도 반대쪽 픽셀을 사용합니다.

## 후처리 수정 및 검증

블러 기본 강도 0을 2로 수정했습니다. 효과를 켤 때 강도가 0이면 기본값을 적용하고 전체 후처리 우회를 해제합니다. 흑백 모드에서도 색수차가 작동하도록 색과 알파를 함께 계산합니다. 블러는 가우시안 샘플링, 에지는 Sobel, 계조는 Bloom 이후의 정규화된 값으로 처리합니다. 스캔라인의 저해상도 샘플링 문제를 수정했습니다. 대칭 소재에서는 미러·만화경의 변화가 작을 수 있습니다.

`.qa/renderer-audit.html`에서 실제 GPU 출력 160건(기존 효과·타일링·극좌표·디렉셔널 블러 41건과 119종 소재 각각의 비어 있지 않은 농도 변화 출력)을 검사했고 모두 통과했습니다. 결과는 `.qa/renderer-audit-result.json`입니다. 반복 보기 전후 줌·이동 유지, UI 125% 배율, 패널 드래그·키보드 조절 및 소재 필터·경계 표시를 브라우저에서 확인했습니다.

## 저장

1. **Save Export**에서 형식과 해상도를 선택합니다.
2. **파일 만들기**를 누릅니다.
3. 생성 후 표시된 **다운로드 링크**를 누릅니다. 자동 다중 다운로드 권한이 필요하지 않습니다.

| 형식 | 내용 |
| --- | --- |
| PNG | 64~2048px. 투명 RGBA, 검정 배경 RGB, 흑백 알파 마스크. |
| 시트 PNG | 4/8/16/32/64프레임, 2/4/8열. 가로·세로 최대 4096px. 행 우선 재생. |
| 시트 JSON | 셀 크기, 열·행, 프레임 수, 각 프레임 좌표와 시간, FPS, 길이. PNG와 별도 링크로 저장. |
| GIF | 최대 512px·128프레임. 고정 256색 팔레트. 투명도는 켜짐/꺼짐이며 PNG의 부드러운 알파와 다릅니다. |
| 노멀맵 | 최종 합성 농도의 높이 차에서 생성하는 근사 노멀맵. 강도와 Y 반전 지원. |
| 채널 패킹 | RGBA 각각에 컬러 R/G/B, 알파, Normal X/Y/Z, 0, 1 배치. |

GIF 시간은 1/100초 단위이며 프레임 지연을 분산해 총 재생 길이를 맞춥니다. 프레임이 많을수록 파일이 커질 수 있습니다. GIF(Graphics Interchange Format)는 CompuServe Incorporated가 정의한 형식입니다.

투명 PNG는 비선곱(straight) 알파입니다. 농도를 마스크로 읽으려면 A 채널을 읽거나, **A · 흑백 마스크**를 저장해 RGB를 읽으세요. 노멀맵은 수학적 높이 추정이며 실제 3D 조명이나 유체 시뮬레이션 결과가 아닙니다.

## 프리셋

**프리셋 저장** → JSON 다운로드 링크를 눌러 전체 작업을 보관합니다. **불러오기**에서 해당 JSON을 선택하면 복원합니다. 초기 Ember v1 JSON도 주요 설정을 변환해 불러옵니다. 브라우저별 파일 접근 권한은 브라우저 자체에서 관리합니다.

## 개발과 확인

`index.html`, `style.css`, `catalog.js`, `model.js`, `post-shader.js`, `renderer.js`, `gif.js`, `layout.js`, `view.js`, `app.js`를 수정한 뒤 `node build.mjs`를 실행하면 단일 파일 `Ember.html`을 다시 만듭니다.

`node verify.mjs`는 프리셋 검증·잘못된 입력·노멀맵·채널 패킹·단일 파일 묶음을 검사하고 `.qa/encoder.gif`를 생성합니다. GIF 픽셀과 프레임은 별도 이미지 디코더로 검사했습니다. 실제 브라우저에서 레이어 복제·실행 취소·재생·샘플·PNG/GIF/시트/노멀맵/패킹/JSON 다운로드를 확인했습니다. 프리셋 파일 선택 자동화는 브라우저 확장의 파일 URL 접근 제한 때문에 끝까지 확인하지 못했고, 파싱·검증 및 저장/복원 데이터는 별도로 검사했습니다.

이전 구현은 `backup-v1/`에 보관했습니다.

이번 극좌표·디렉셔널 블러·UI 업데이트 이전 파일은 같은 폴더의 `backup-before-polar-ui/`에 보관했습니다. 실행 파일은 계속 `Ember.html`입니다. 이미 열어둔 경우 새로고침하거나 닫았다가 다시 열어주세요.

## 다른 컴퓨터와 로컬 기록

개발을 이어갈 때는 `AGENTS.md`와 `HANDOFF.md`부터 읽습니다. 자세한 이동·Git 동기화 절차는 [PORTABILITY.md](PORTABILITY.md)에 있습니다. `node scripts/checkpoint.mjs`는 빌드·검증 후 로컬 커밋과 `_backups/`의 ZIP을 생성하며, `--sync`를 붙이면 지정한 원격 저장소에 push합니다. Windows에서는 `Save-Local.cmd` 또는 `Save-and-Sync.cmd`로 실행할 수 있습니다. 작업 JSON은 `presets/`, 보관할 결과는 `exports/`에 넣으면 함께 기록됩니다. 브라우저 자동 저장은 따로 JSON으로 내보내야 이동할 수 있습니다.
